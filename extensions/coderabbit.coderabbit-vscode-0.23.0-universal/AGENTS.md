# VS Code extension test ownership

- Exercise review admission and file history through the real command and
  request payload. Keep billing consent, cancellation and upload containment
  assertions at those boundaries rather than exporting helper predicates.
- Use real filesystem fixtures for containment and race regressions. Assert
  safe bytes reach the serialized request as well as excluding external
  secrets; empty or unexercised uploads are insufficient negative proof.
- Test browser login context at its actual admission, callback and continuation
  owner. Seed stale state before cleanup assertions and keep negative inputs
  valid except for the guard under test. Preserve other clients' state.
- Exercise the mounted webview and registered host message receiver for UI and
  handshake behavior. Keep visual styling out of unit assertions.
- Mock external I/O instead of reproducing the policy being asserted. Resolve
  real AI handler registrations and principal derivation when those are the
  contract. Distinguish captured editor calls from actual native execution.
- Keep native and release harnesses in their owning runner. Missing platform
  capabilities must be reported as explicit skips or unrun limits.
